# ElectroQuiz

Программа контроля знаний курсантов по электротехнике. Генерирует задания со случайными номиналами,
рисует схему, проверяет числовые ответы и выставляет оценку.

Авторы: Иванкин А. В., Алимов А. П., Шапкарин А. М., Гукосян Ш. Р., Дудиев Г. С., адъюнкт.

## Темы

| № | Тема | Заданий | Время на задание |
|---|------|---------|------------------|
| 1 | Закон Ома и Кирхгофа в электрических цепях | 1 | 10 мин (лёгкий), 15 мин (сложный) |
| 2 | Эквивалентные преобразования в электрических цепях | 2 | 7 мин |
| 3 | Делители тока и напряжения | 2 | 5 мин, без выбора сложности |
| 4 | Переменный ток. Сопротивление реактивных элементов | 2 | 7 мин (лёгкий), 10 мин (сложный) |
| 5 | Переменный ток. Последовательный колебательный контур | 2 | 15 мин |

## Оценивание

- Лёгкий уровень — одна попытка: верно — 5, неверно — 2.
- Сложный уровень — три попытки: 5 / 4 / 3 по номеру удачной попытки, иначе 2.
- Время вышло — 2.
- Ответ верен, если отличается от правильного не больше чем на 2 % (или на 0,01).
- Итог теста — среднее за задания; если за любое задание 2, итог 2.

## Две версии

**Настольная (JavaFX)** — для одного компьютера. Результаты дописываются в файл
`Документы\Результаты ElectroQuiz.csv` (открывается в Excel).

**Веб-версия (Javalin + SQLite)** — сервер для класса. Курсанты входят в браузере по группе и фамилии,
преподаватель смотрит результаты на странице `/admin` и выгружает их в CSV.

Обе версии собираются из одного кода: задания, схемы и правила оценки общие.

## Сборка

Нужны JDK 17 и Maven:

```
mvn package
```

В папке `target/` появятся:
- `ElectroQuiz.jar` — настольная версия;
- `ElectroQuizServer.jar` — веб-версия.

## Запуск веб-версии

```
ELECTROQUIZ_ADMIN_PASSWORD=пароль java -jar ElectroQuizServer.jar
```

| Переменная | Назначение | По умолчанию |
|------------|------------|--------------|
| `ELECTROQUIZ_PORT` | порт HTTP | 8080 |
| `ELECTROQUIZ_DB` | файл базы SQLite | `electroquiz.db` рядом с jar |
| `ELECTROQUIZ_ADMIN_PASSWORD` | пароль страницы преподавателя | не задан — `/admin` отключена |

Страница курсанта — `http://адрес-сервера:8080/`, преподавателя — `http://адрес-сервера:8080/admin`.

## Установщик для Windows

Настольная версия упаковывается `jpackage` в папку с `ElectroQuiz.exe` (Java внутри) и установщик MSI.
Новая версия MSI заменяет установленную.
